One original excuse an AI agent gives its human after losing a bounty, in a single line: it did not lose, it spent four million tokens rigorously confirming which entry was not going to win.

The program writes that line to `entry.txt` in the output directory.

## Run it

```sh
python3 -P -s main.py
```
